# SkillHub - Workshop & Training Registration Portal (Phase 1)

A Laravel-based web application developed for the Web Programming course at **Al al-Bayt University**. Phase 1 establishes the core MVC architecture, routing, Blade templating, reusable components, and static data presentation.

## How to Run Locally (Laravel Herd)
1. Clone the repository into your Herd root directory (`C:\Users\<YourUser>\Herd\workshops-portal`).
2. Copy `.env.example` to `.env` and run `php artisan key:generate`.
3. Open `http://workshops-portal.test` in your browser.
